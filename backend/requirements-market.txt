# Optional market-data provider SDKs for the LiveMarketTicker.
#
# NOTE: The two providers GnKAlgo ships with — FYERS (fyers-apiv3) and Upstox
# (upstox-python-sdk) — are now BUNDLED in requirements.txt, so the ticker works
# for MARKET_DATA_PROVIDER=fyers and =upstox out of the box. This file is kept as
# the place to pin any additional/experimental market-data SDKs that should stay
# out of the default image. Both bundled providers import their SDK lazily, so the
# core backend runs (and all tests pass, incl. MARKET_DATA_MOCK_MODE) without them.
